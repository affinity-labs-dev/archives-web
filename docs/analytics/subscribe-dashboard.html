Questions This Data Answers

1. How many users see the paywall?

  1. Total paywall impressions: — subscribe_screen_viewed count
  2. Unique users: — Use PostHog Trends with unique users math on subscribe_screen_viewed

2. What triggers bring users to the paywall?

  1. Trigger distribution: — Breakdown subscribe_screen_viewed by trigger property
  2. Most effective trigger: — Compare trigger breakdown against subscribe_purchase_completed with same breakdown

3. What % start a purchase after viewing?

  1. View-to-start rate: — subscribe_purchase_started / subscribe_screen_viewed
  2. Per-user funnel: — PostHog Funnel: subscribe_screen_viewed → subscribe_purchase_started

4. What % complete the purchase?

  1. Start-to-complete rate: — subscribe_purchase_completed / subscribe_purchase_started
  2. Overall conversion: — subscribe_purchase_completed / subscribe_screen_viewed

5. What is the purchase failure rate?

  1. Failure rate: — subscribe_purchase_failed / subscribe_purchase_started
  2. Cancel vs fail: — Compare subscribe_purchase_cancelled vs subscribe_purchase_failed to distinguish user-initiated vs technical failures

6. How often do users restore purchases?

  1. Restore attempt rate: — subscribe_restore_tapped / subscribe_screen_viewed
  2. Restore success rate: — subscribe_restore_success / subscribe_restore_tapped
  3. Restore failure rate: — subscribe_restore_failed / subscribe_restore_tapped
