Questions This Data Answers

1. How many users view the daily story?

  1. Total views (30d): daily_story_viewed event count
  2. Unique users: Use PostHog Trends with unique users math on daily_story_viewed

2. What % start after viewing?

  1. Start rate: daily_story_started / daily_story_viewed
  2. Per-user funnel: PostHog Funnel → daily_story_viewed → daily_story_started (unique users)

3. What % complete the daily story?

  1. Completion rate: daily_story_completed / daily_story_viewed
  2. Start-to-completion rate: daily_story_completed / daily_story_started

4. What % dismiss before completing?

  1. Dismiss rate: daily_story_dismissed / daily_story_viewed
  2. Dismiss vs complete ratio: Compare daily_story_dismissed and daily_story_completed counts side by side

5. What is the average streak length?

  1. Average streak: Average of current_streak property on streak_viewed
  2. Streak distribution: Breakdown of streak_viewed by current_streak value
  3. Max streak: Max of current_streak on streak_viewed
