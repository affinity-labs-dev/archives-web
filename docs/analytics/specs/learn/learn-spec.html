Analysis Notes

  • Exclude dismissed lessons from completion rate: Users who tap the X button to exit a lesson mid-progress should not count as drop-offs in the lesson completion funnel. Once lesson_dismissed is implemented, filter by it when calculating lesson → quiz conversion.
  • Exclude backgrounded sessions: A user backgrounding the app during a lesson or quiz is not a drop-off. Use app lifecycle events (app_backgrounded / app_foregrounded) to stitch sessions. Only count a user as dropped if they never return to finish.
  • Quiz retakes are not separate funnels: A retake (quiz_retake) feeds back into the same quiz. When calculating quiz completion rates, count the final attempt only. Use is_retake on quiz_completed to distinguish first attempts from retakes.
  • Video buffering context: video_buffering events contain the CDN URL — use this to correlate buffering with specific CloudFront distributions or HLS vs progressive format.
  • module_completed vs lesson_completed: lesson_completed fires per-lesson (a module may have multiple lessons). module_completed fires once after the quiz is passed for a module. These are distinct funnel stages.
