Questions This Flow Answers

1. Strategic Questions

  1. Where is the major drop-off in the onboarding funnel?
  2. How many users tap the back button at least once during onboarding?
  3. Which screen has the highest back-button rate?
  4. How many users background the app during onboarding and never come back?
  5. How many users background the app but return and finish onboarding?
  6. How long does the average user take to complete the full onboarding?
  7. How many users skip one or more personalization screens?
  8. How many users complete all personalization screens?

2. Behavioral Insights

  1. How many users see the Hero Screen?
  2. How many users select at least one interest at the Interests Selection screen?
  3. How many users reach the Create Account screen?
  4. How many users successfully sign up (new account created)?
  5. How many users sign in with an existing account instead of signing up?
  6. How many users choose Apple as their auth method?
  7. How many users choose Google as their auth method?
  8. How many users choose Email as their auth method?
  9. How many users fail authentication (and what errors do they hit)?
  10. How many users enable push notifications at the Notification Permission screen?
  11. How many users decline push notifications?
  12. How many users tap "Maybe later" on notifications?
  13. How many users select each daily learning goal option (5 / 10 / 15 / 20 min)?
  14. How many users are in each age group (13-17 / 18-24 / 25-34 / 35-44 / 45+)?
  15. How many users complete the full onboarding (tap GET STARTED at Learning Path Overview)?
  16. How many users see the Soft Paywall?
  17. How many users tap "See my free offer" on the Soft Paywall?
  18. How many users see the Custom Paywall?
  19. How many users select a subscription plan on the Custom Paywall?
  20. How many users successfully subscribe during onboarding?
  21. How many users dismiss the Custom Paywall without subscribing?
  22. How many returning users land on the Welcome Back screen?
  23. How many returning users re-authenticate via one-tap on Welcome Back?

3. Checkpoint Validation

  1. App Opened — How many users reach the routing guard?
  2. Hero Screen — How many users see the first onboarding screen?
  3. Name Input — How many users reach the name input screen?
  4. Interests Selection — How many users select interests and continue?
  5. Create Account — How many users reach the auth screen?
  6. Notification Permission — How many users reach the notification prompt?
  7. Learning Path Overview — How many users see their personalized path and tap GET STARTED?
  8. Soft Paywall — How many users see the soft paywall?
  9. Custom Paywall — How many users see the subscription plans?
  10. Main App — How many users land in the main app after onboarding?

Analysis Notes

  • Exclude skips from drop-off: Users who tap Skip or Maybe later are intentional — they should not count as drop-offs. Filter by onboarding_skipped events when calculating funnel conversion rates.
  • Exclude backgrounded sessions: A user backgrounding the app is not a drop-off. Use onboarding_app_backgrounded / onboarding_app_foregrounded to stitch sessions. Only count a user as dropped if they never return.
  • Back-button navigation ≠ drop-off: Users going back to change an answer should be tracked via onboarding_back_tapped but not counted as abandonment.
