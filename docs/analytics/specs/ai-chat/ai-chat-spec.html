Questions This Flow Answers

1. Strategic Questions

  1. How many users open the AI chat at least once per week?
  2. How many users open AI chat from the floating button vs from Chat to Learn?
  3. How many users hit the monthly quota limit?
  4. How many free users hit the quota limit and then see the paywall?
  5. How many users who hit the quota limit upgrade to a paid plan?
  6. How many AI chat sessions result in zero messages sent (opened and dismissed immediately)?
  7. How many users send image-related requests (generation, editing, analysis)?
  8. How many users use the AI chat more than 5 times in a single day?

2. Behavioral Insights

  1. How many users tap a suggestion on the welcome screen as their first message?
  2. How many users type a custom first message instead of tapping a suggestion?
  3. How many users receive a response with web search sources?
  4. How many users tap on a web search source link?
  5. How many users request image generation through text prompts?
  6. How many users upload an image from their photo library?
  7. How many uploaded images are analyzed vs edited?
  8. How many users open the full-screen image viewer?
  9. How many users share a generated or edited image?
  10. How many users open the action menu (plus button)?
  11. How many users select a quick prompt from the action menu?
  12. How many users clear their chat history?
  13. How many users encounter an AI chat error?
  14. How many users complete a Chat to Learn session (quiz context + AI response)?
  15. How many users send a follow-up message after a Chat to Learn response?

3. Checkpoint Validation

  1. AI Chat Viewed — How many users open the chat modal?
  2. Message Sent — How many users send at least one message?
  3. Text Response — How many messages get a successful AI response?
  4. Image Generated — How many users request and receive a generated image?
  5. Chat Dismissed — How many users close the chat after at least one exchange?

Analysis Notes

  • Chat to Learn is gated by subscription: Non-subscribers see a paywall when tapping "Chat to Learn" on quiz results. Track conversion rate from chat_to_learn_paywall_shown to subscribe_purchase_completed with trigger chat_to_learn.
  • Quota enforcement is server-side: The client checkQuota() always returns allowed: true. The backend API returns HTTP 429 when the limit is hit. The ai_quota_exceeded event fires on the client when the backend rejects a request.
  • Image routing is heuristic: isImageRequest() and isImageEditRequest() use keyword matching. Some prompts may be misclassified (image intent routed to text chat or vice versa).
  • Suggestion tap vs typed message: Both go through the same handleSend() path and fire ai_chat_message_sent. To distinguish them, add ai_suggestion_tapped on the welcome screen.
  • Chat to Learn auto-context: When the user taps "Chat to Learn" after a quiz, a hidden context message is sent to the AI automatically. This is not a user action. The AI response appears with a quiz context banner. The chat_to_learn_response event tracks this.
  • Floating button is hidden on certain screens: Hidden on onboarding, auth, today tab, and subscribe screens. Track ai_button_visible to understand which screens drive the most chat opens.
