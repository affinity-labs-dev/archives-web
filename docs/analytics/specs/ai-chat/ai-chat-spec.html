Questions This Flow Answers

1. Strategic Questions

  1. How many users open the AI chat at least once per week?
  2. How many users open AI chat from the floating button?
  3. How many users open AI chat from the "Chat to Learn" button on quiz results?
  4. How many users hit the monthly quota limit?
  5. How many free users hit the quota limit and then see the paywall?
  6. How many users who hit the quota limit upgrade to a paid plan?
  7. How many AI chat sessions result in zero messages sent (user opened and closed immediately)?
  8. How many users send image-related requests (generation, editing, analysis)?
  9. How many users use the AI chat more than 5 times in a single day?

2. Behavioral Insights

  1. How many users tap a suggestion button on the welcome screen as their first interaction?
  2. How many users type a custom first message instead of using suggestions?
  3. How many users send a text message in the AI chat?
  4. How many users receive a chat response with web search sources?
  5. How many users tap on a web search source link?
  6. How many users request image generation through text prompts?
  7. How many users upload an image from their photo library?
  8. How many uploaded images are analyzed (asked about) rather than edited?
  9. How many uploaded images are edited (transformed)?
  10. How many users open the full-screen image viewer?
  11. How many users share a generated or edited image?
  12. How many users open the action menu (plus button)?
  13. How many users select a quick prompt from the action menu?
  14. How many users clear their chat history?
  15. How many users encounter an AI chat error?
  16. How many users dismiss the Chat to Learn paywall without subscribing?
  17. How many users complete a Chat to Learn session (quiz context + AI response)?
  18. How many users send a follow-up message after a Chat to Learn response?

3. Checkpoint Validation

  1. Floating AI Button — How many users see the floating button on app screens?
  2. AI Chat Modal (Welcome) — How many users open the chat modal and see the welcome screen?
  3. Chat Response Received — How many users send a message and get a successful AI response?
  4. Image Generated — How many users request and receive a generated image?
  5. Chat Closed — How many users close the chat after at least one exchange?

Analysis Notes

  • Chat to Learn is gated by subscription: Non-subscribers see a paywall when tapping "Chat to Learn" on quiz results. Track conversion rate from chat_to_learn_paywall_shown to subscribe_purchase_completed with trigger chat_to_learn.
  • Quota enforcement moved server-side: The client-side checkQuota() in AIStorageService now always returns allowed: true. Actual quota enforcement is handled by the backend API (returns HTTP 429). The ai_quota_exceeded event fires on client when the backend rejects a request.
  • Image request detection is heuristic: The isImageRequest() and isImageEditRequest() methods use keyword matching. Some user prompts may be misclassified (image intent routed to text chat or vice versa). Adding ai_image_generation_requested would help measure false-negative rate.
  • Session-based storage: Messages are stored per-session in Supabase ai_user_data table. The ai_chat_session_duration event would enable session-length analysis without relying on timestamp math between open/close events.
  • Floating button is hidden on certain screens: The button is hidden on onboarding, auth, today tab, and subscribe screens. Track ai_button_visible to understand which screens drive the most chat opens.
  • Cloud sync for messages: Messages sync to Supabase with 1.5s debounce. If the user closes the app immediately after sending, the last message may not sync. The ai_chat_history_loaded event with source would help diagnose sync issues.
