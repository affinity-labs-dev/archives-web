Quiz Completion Rate (Real Data)

82%
49,552 completed / 60,130 started

18% of started quizzes are NOT completed. After deploy, quiz_abandoned will show at which question users quit.

Video Watch-Through Rate (Real Data)

41%
28,218 completed / 69,209 played

Most videos are started but not watched to end. This is expected — users may expand reading card mid-video.

Module Completion Rate (Real Data)

67%
36,420 completed / 54,649 started

33% of started modules don't reach completion (all lessons + quiz).

Gap Filled by AFF-857

We can see 26% of lessons aren't completed and 18% of quizzes aren't finished — but until now we had no idea when users leave. After deploying:

  • lesson_dismissed → tells us which lesson type loses people + how long they stayed
  • quiz_abandoned → tells us at which question users quit + total time invested
  • adventure_card_dismissed → tells us if the adventure detail modal converts to starting a module

Questions This Data Answers

1. Lesson Engagement (now answerable with lesson_dismissed)

  1. What % of lessons are abandoned before completion? — lesson_dismissed / lesson_started
  2. Which lesson type has the highest drop-off? — Breakdown lesson_dismissed by lesson_type
  3. How long do users spend before quitting a lesson? — Median time_spent_seconds on lesson_dismissed
  4. Is it the first lesson in a module that loses people? — Breakdown by lesson_id

2. Quiz Engagement (now answerable with quiz_abandoned)

  1. What % of quizzes are abandoned? — quiz_abandoned / quiz_started
  2. At which question do most users quit? — Average questions_answered on quiz_abandoned
  3. How long before users give up on a quiz? — Median time_spent_seconds on quiz_abandoned
  4. Which modules have the highest quiz abandonment? — Breakdown by module_id

3. Adventure Card (now answerable with adventure_card_dismissed)

  1. How long do users look at adventure details before dismissing? — Median time_on_card_seconds
  2. What % of card views convert to starting a module? — module_started / adventure_started

4. Already Answerable (pre-existing events)

  1. Full learn funnel conversion: era → adventure → module → lesson → quiz → complete
  2. Average quiz score / retake rate: quiz_completed properties
  3. Video engagement: play/pause/complete rates
  4. Reading engagement: reading_card_expanded rate
  5. First-time user activation: first_lesson event
