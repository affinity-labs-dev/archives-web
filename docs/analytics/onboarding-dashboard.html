Coverage Status

CategoryStatusExplanation
Step views (13 screens) All wired Every onboarding screen fires onboarding_step_viewed on mount.
Back taps (all back buttons) All wired OnboardingHeader screenName prop auto-tracks all back presses. Standalone back arrows (step-6, step-7, auth, paywall) also tracked inline.
Skips (4 screens) All wired name_input, interests, daily_goal, age_group — all fire onboarding_skipped.
Question answers (4 questions) All wired Each question fires its own event + all are bundled in onboarding_completed.
App background/foreground PostHog auto-capture PostHog SDK fires Application Backgrounded and Application Opened automatically. Correlate with the last onboarding_step_viewed in the session to know which screen the user was on.
Custom Paywall Screen not built The soft paywall CTA currently routes directly to main app. Custom paywall with plan selection is a future feature — events will be added when the screen is built.
