Questions This Data Answers

1. Funnel Drop-off (answerable with onboarding_step_viewed)

  1. Which screen do users drop off at? — Compare onboarding_step_viewed counts per screen
  2. How many see Hero vs reach Create Account? — Funnel from hero → create_account
  3. What's the overall onboarding completion rate? — onboarding_completed / onboarding_step_viewed (hero)
  4. How long does onboarding take? — Median time_to_complete_seconds on onboarding_completed

2. Skip & Friction (answerable with onboarding_skipped + onboarding_back_tapped)

  1. What's the skip rate per screen? — onboarding_skipped breakdown by screen
  2. Which screen has the most back-taps? — onboarding_back_tapped breakdown by screen
  3. Is the auth screen a friction point? — Back-tap count on create_account vs other screens

3. User Preferences (answerable with individual question events)

  1. What motivates users? — onboarding_interests_selected breakdown by interests
  2. What daily goal do users set? — onboarding_daily_goal_selected breakdown by daily_goal_minutes
  3. What's the age distribution? — onboarding_age_group_selected breakdown by age_group
  4. Which auth method is preferred? — auth_method_selected breakdown by auth_method

4. Paywall & Returning Users

  1. What % tap the paywall CTA? — paywall_cta_tapped / paywall_viewed
  2. Do returning users continue or sign out? — welcome_back_tapped breakdown by action
  3. What's the push notification opt-in rate? — push_notifications_enabled / (enabled + declined)

5. Already Answerable (pre-existing events)

  1. Total sign-ups: user_signed_up
  2. Auth success rate: auth_succeeded / user_signed_up
  3. Era preference at onboarding: era_selected breakdown
  4. Question responses: onboarding_question_answered (legacy)
