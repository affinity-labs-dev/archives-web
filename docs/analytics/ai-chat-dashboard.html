Questions This Data Answers

1. How often is AI Chat used?

  1. Total chat sessions: ai_chat_opened count over 30 days
  2. Messages sent vs sessions: Ratio reveals engagement depth per session

2. What triggers AI Chat (fab, quiz_results, profile)?

  1. Trigger breakdown: ai_chat_opened broken down by trigger property
  2. Most common entry point: Which UI element drives the most chat sessions

3. How many messages per session?

  1. Average messages: ai_chat_message_sent / ai_chat_opened
  2. Engagement depth: Higher ratio = users asking follow-up questions

4. How fast are AI responses?

  1. Median response time: Median response_time_ms on ai_chat_response_received
  2. Performance monitoring: Track if Gemini API latency is acceptable

5. How long are chat sessions?

  1. Session duration: Median session_duration_seconds on ai_chat_closed
  2. Engagement quality: Longer sessions suggest deeper conversations

6. How many users hit the monthly quota?

  1. Quota reached count: ai_chat_quota_reached events
  2. Limit adjustment signal: High counts may indicate the quota is too low

7. How often is image generation used?

  1. Image generation count: ai_chat_image_generated events
  2. Feature adoption: Ratio to total messages shows how popular image gen is
