How files connect
Tokens theme.ts
The single source of truth. All colors, typography, spacing, shadows, and button tokens live here. Every section component imports from this file — nothing is hardcoded in the sections.
import { colors, typography, spacing } from '../theme';
  • colors15 palette colors (Acai, Blue, Accent, Neutral, Success, Error)
  • buttonTokensSemantic tokens for 4 button types (surface, shadow, border, text)
  • typography12 type styles across Display, Heading, Body, Label
  • fontsFont family name constants (Bounded, Onest weights)
  • spacing8 spacing tokens (2px to 48px)
  • borderRadius6 radius values (8px to pill)
  • shadows3 elevation levels (small, medium, large)
  • colorSwatchesDisplay metadata for rendering color cards
  • typographyRowsDisplay metadata for rendering type samples
  • buttonTokenRowsDisplay metadata for rendering token rows
Screen PlaygroundScreen.tsx
The main entry point. Loads Bounded + Onest fonts, shows a loading spinner until ready, then renders all 5 section components in a scrollable view.
←sections/TypographySection.tsx
←sections/ColorsSection.tsx
←sections/ButtonsSection.tsx
←sections/SpacingSection.tsx
←sections/ComponentsSection.tsx
←assets/fonts/*.ttf(loaded via useFonts)
Sections sections/*.tsx
Each section is a self-contained React Native component. They all follow the same pattern: section header, blue badge labels, dividers, and StyleSheet.create for styles. All import tokens from theme.ts — nothing from the old ArchivesTheme.
←theme.ts(colors, typography, spacing, shadows)
←react-native-svg(ButtonsSection only, for Apple icon)
Route app/playground.tsx
A single re-export line that makes the playground accessible at /playground in the app.
export { default } from '@/DesignPlayground/PlaygroundScreen';
How to use
In-App View in the app
// Navigate from anywhere in the app import { router } from 'expo-router'; router.push('/playground');
Import Use tokens in your code
// Import the full screen import { PlaygroundScreen } from '@/DesignPlayground'; // Import just the tokens you need import { colors, typography, spacing } from '@/DesignPlayground/theme'; // Use in styles backgroundColor: colors.acaiPrimary, // '#3E2368' ...typography.heading.xl, // Onest Black 30 padding: spacing.md, // 16
