# Audio Assets

This directory contains background music and audio files for the Archives app.

## Files
- `palace-ambience.mp3` - Background music for Adventure 1 Module 2 Lesson 1 (Palace Interior Carousel)

## Usage
Audio files are loaded using expo-av and require() statements in React Native.

## File Requirements
- Format: MP3 or M4A (iOS compatible)
- Quality: Compressed for mobile (128kbps recommended)
- Duration: Should support looping for continuous playback
- Volume: Mixed at lower levels to not interfere with UI sounds
